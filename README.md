# Enter News — enternews.mn

**Нэг товшилтоор дэлхийг мэд**

Enter News мэдээллийн сайтын вэб хуудас. Хар-улаан брэнд загвартай, гадаадын том мэдээний сайтын (BBC, CNN, Guardian) бүтэцтэй: нүүр хуудас, ангилал бүрийн хуудас, мэдээний дэлгэрэнгүй хуудас (`#news-1`), хайлт, видео хэсэг.

## Файлууд

```
index.html                 – Үндсэн хуудас (бүх код нэг файлд)
404.html                   – "Хуудас олдсонгүй" хуудас
assets/logo.png            – Хар дэвсгэртэй лого
assets/logo-white.png      – Цагаан дэвсгэртэй лого
assets/cover.jpg           – Facebook cover
assets/favicon.png         – Браузерын жижиг дүрс
assets/apple-touch-icon.png
.nojekyll                  – GitHub Pages-д шаардлагатай
```

## GitHub Pages дээр нийтлэх

1. GitHub дээр **New repository** дарж `enternews` нэртэй, **Public** репо үүсгэнэ.
2. **Add file → Upload files** дараад энэ хавтасны **бүх файл, хавтсыг** (assets хавтастай нь) чирж оруулаад **Commit changes** дарна.
3. **Settings → Pages** руу орж *Source* хэсэгт **Deploy from a branch**, branch-ийг **main**, хавтсыг **/ (root)** гэж сонгоод **Save** дарна.
4. 1–2 минутын дараа сайт `https://ТАНЫ-НЭР.github.io/enternews/` хаяг дээр нээгдэнэ.

## enternews.mn домэйн холбох

1. **Settings → Pages → Custom domain** хэсэгт `enternews.mn` гэж бичээд **Save** дарна.
2. Домэйн бүртгүүлсэн газрынхаа DNS тохиргоонд дараах бичлэгүүдийг нэмнэ:
   - `A` бичлэг (@): `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` бичлэг (www): `ТАНЫ-НЭР.github.io`
3. DNS шинэчлэгдсэний дараа **Enforce HTTPS**-г асаана.

## Мэдээ засах

Мэдээнүүд `index.html` доторх `N` жагсаалтад байна. Одоогийнх нь **жишээ мэдээ** тул өөрийн мэдээгээр солиорой:

```js
{id:21, cat:'society', time:'Дөнгөж сая', read:3,
 title:'Мэдээний гарчиг',
 sub:'Товч агуулга...',
 img:'assets/photos/medee21.jpg'}   // зураг: assets/photos хавтсанд хийнэ
```

Ангилал (`cat`): `politics`, `economy`, `world`, `society`, `tech`, `sport`, `culture`, `video`. Шууд мэдээнд `live:true`, видеонд `dur:'3:12'` нэмнэ.

## Бичлэгийн дэлгэц

Сайт руу ороход баруун доод буланд жижиг бичлэгийн дэлгэц гарч, бичлэг шууд (дуугүйгээр) тоглож эхэлнэ. Хуудсыг гүйлгэхэд ч үргэлж харагдана. ⏭ товч дарахад дараагийн бичлэг, ✕ дарахад хаагдана. Бичлэгийг `index.html` доторх `VIDEOS` жагсаалтаас засна:

```js
// Өөрийн mp4 файл (assets/videos хавтсанд хийнэ, 100MB-аас бага байх ёстой):
{title:'Бичлэгийн гарчиг', src:'assets/videos/medee.mp4', poster:'assets/videos/medee.jpg', dur:'3:12', time:'2 цагийн өмнө'}
// YouTube бичлэг (https://www.youtube.com/watch?v=ABC123 → youtube:'ABC123'):
{title:'Бичлэгийн гарчиг', youtube:'ABC123', dur:'6:40', time:'Өнөөдөр'}
```

Хөтчүүд дуутай бичлэгийг автоматаар тоглуулахыг хориглодог тул бичлэг дуугүй эхэлнэ. Уншигч бичлэгийн доорх дууны товчийг дарж дууг асаана. Жагсаалтын эхний бичлэг сайт нээгдэхэд тоглоно.

## Бидний тухай · Холбоо барих · Сурталчилгаа хуудсууд

- `#about` — Enter News-ийн танилцуулга, үнэт зүйлс, сэдвүүд
- `#contact` — бүх холбоо барих мэдээлэл, мессеж илгээх маягт
- `#advertise` — хамтран ажилладаг байгууллагууд, сурталчилгааны байршил

Холбоо барих мэдээллийг `CONTACT` хэсгээс засна (Facebook, YouTube холбоос, хаяг, ажлын цаг). Хамтрагч байгууллагуудыг `PARTNERS` жагсаалтаас засна; лого нь `assets/partners/` хавтсанд:

```js
{name:'Байгууллагын нэр', type:'Сурталчилгааны захиалагч', text:'Товч танилцуулга', url:'https://...', logo:'assets/partners/logo.png'}
```

## Сурталчилгааны дэлгэц

Хажуу талд 300×250 хэмжээтэй сурталчилгааны дэлгэц байнга эргэлдэж харагдана (нүүр, ангилал, мэдээний хуудас бүрт). Сурталчилгааг `index.html` доторх `ADS` жагсаалтаас засна:

```js
{tag:'Захиалагч', title:'Гарчиг', text:'Тайлбар', cta:'Дэлгэрэнгүй',
 href:'https://захиалагчийн-сайт.mn',
 img:'assets/ads/zahialagch.jpg'}   // 300×250 зураг өгвөл зураг нь бүтнээрээ гарна
```

`AD_MS` — нэг сурталчилгаа харагдах хугацаа (одоо 6 секунд).
